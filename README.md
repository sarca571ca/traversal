# Traversal

A desktop navigation and scanning tool for EVE Online, focused on Pochven but usable across all space types. Tracks characters in real time via ESI, maps wormhole connections, records signatures, and displays the full Pochven highway topology.

> **Note:** Approximately 95% of this project's code was generated by [Claude](https://claude.ai) (Anthropic's AI assistant) as an experiment in AI-driven development. The remaining ~5% consists of manual layout and UI adjustments.

---

## Features

- Real-time character location tracking via ESI
- Automatic wormhole connection mapping as characters jump
- Signature management per system (wormholes, combat, data/relic sites)
- Full Pochven highway layout pre-seeded with correct conduit topology
- J-space system info: wormhole class and static connection types on selection
- Route planning through Pochven
- Connection metadata: wormhole type, ship size, mass status, EOL timer

## Prerequisites

| Tool | Version | Notes |
|------|---------|-------|
| [Go](https://go.dev/dl/) | 1.21+ | Required for backend compilation |
| [Node.js](https://nodejs.org/) | 18+ | Required for frontend build |
| [Wails v2](https://wails.io/docs/gettingstarted/installation) | v2.x | The desktop app framework |
| GCC / CGo toolchain | any | Required by `go-sqlite3` (uses CGo) |

### Installing Wails

```sh
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

Verify with:

```sh
wails doctor
```

This will flag any missing system dependencies (WebKit2GTK on Linux, WebView2 on Windows, etc.).

### Linux extra dependencies (Debian/Ubuntu)

```sh
sudo apt install gcc libgtk-3-dev libwebkit2gtk-4.0-dev
```

### Linux extra dependencies (Arch)

```sh
sudo pacman -S gcc webkit2gtk
```

## EVE Online ESI Application

Traversal authenticates characters via EVE's OAuth2 SSO. You need to register an application on the [EVE Developer Portal](https://developers.eveonline.com/):

1. Create a new application
2. Set the callback URL to `https://localhost:8080/callback`
3. Request these scopes:
   - `esi-location.read_location.v1`
   - `esi-location.read_ship_type.v1`
   - `esi-skills.read_skills.v1`
   - `esi-fittings.read_fittings.v1`
   - `esi-clones.read_implants.v1`
4. Note your **Client ID** and **Client Secret**

## Configuration

**Release binaries require no configuration.** The bundled EVE application credentials are used automatically. Just download, run, and add your character.

A `.env` file is only needed if you are a developer who wants to use your own EVE SSO application registration (e.g. to test against a separate app or change the callback URL):

```sh
cp .env.example .env
# then fill in CLIENTID
```

> Note: this app uses PKCE (public client OAuth2 flow). No client secret is required or used.

## Building

### Production binary

```sh
wails build
```

Output: `build/bin/traversal` (Linux/macOS) or `build/bin/traversal.exe` (Windows)

### Development mode (hot reload)

```sh
wails dev
```

Frontend changes reload instantly; Go changes recompile the binary automatically.

### Compile check only (no frontend)

```sh
go build ./...
```

Useful for catching Go errors quickly without a full Wails build.

## First Run

1. Launch the application
2. Click **Add Character** and complete the EVE SSO login in the browser window that opens
3. Click **Seed Pochven** to load the full Pochven highway topology from ESI — this runs once and is required before the map is usable
4. Your character's location will begin tracking automatically every 5 seconds

## Database

Traversal stores all data in a SQLite database at:

| Platform | Path |
|----------|------|
| Linux | `~/.local/share/traversal/traversal.db` |
| macOS | `~/Library/Application Support/traversal/traversal.db` |
| Windows | `%APPDATA%\traversal\traversal.db` |

The database is created automatically on first launch. It is gitignored.

### Resetting the map

To clear the map and re-seed Pochven from scratch (useful after layout changes):

```sh
sqlite3 ~/.local/share/traversal/traversal.db "
  DELETE FROM systems;
  DELETE FROM connections;
  DELETE FROM signatures;
  DELETE FROM settings WHERE key IN (
    'pochven_topology_seeded',
    'pochven_system_ids',
    'home_system_ids',
    'viewport_tx', 'viewport_ty', 'viewport_scale'
  );
"
```

Then relaunch and click **Seed Pochven** again.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Desktop framework | [Wails v2](https://wails.io) |
| Backend | Go |
| Database | SQLite via `mattn/go-sqlite3` |
| ESI client | `antihax/goesi` + raw HTTP for newer endpoints |
| Auth | EVE SSO OAuth2 via `golang.org/x/oauth2` |
| Frontend | Svelte + TypeScript + Vite |
| Caching | memcached (optional, via `bradfitz/gomemcache`) |
